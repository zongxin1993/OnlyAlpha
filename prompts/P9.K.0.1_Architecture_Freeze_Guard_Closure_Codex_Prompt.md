# 7. Workstream A — 真正冻结 Root Python Surface

## 7.1 当前问题

当前 `test_p9_k0_product_surfaces.py` 只读取：

```python
__all__
```

这不能代表实际 module-level reachable names。

Python 中：

```python
from x import Foo
```

即使 `Foo` 不在 `__all__`：

```python
import onlyalpha
onlyalpha.Foo
```

仍可能可达。

因此：

```text
freeze __all__
!=
freeze actual top-level capability exposure
```

---

## 7.2 目标

机械确认：

```text
src/onlyalpha/__init__.py
actual imported/rebound top-level symbols
```

形成一个显式、确定性的 allowlist。

至少区分：

```text
PUBLIC CONTRACT
PUBLIC VALUE / READ-ONLY
KNOWN MIGRATION DEBT
FORBIDDEN MUTATION CAPABILITY
```

不要因为某 symbol 当前可达就自动认为它合理。

---

## 7.3 实现原则

优先使用：

```text
AST import/binding inspection
```

而不是 runtime wildcard tricks。

应能够发现：

```python
from onlyalpha.foo import DangerousWriter
```

即使：

```python
DangerousWriter
```

没有加入 `__all__`。

---

## 7.4 必须保护

至少阻止未来 root package 新增：

```text
Strategy publication capability
Strategy Promotion writer
semantic store writer
PostgreSQL mutation authority
Worker/Scheduler authority
Migration authority
Kernel mutation capability
```

除非 architecture contract 显式更新并经过审计。
