# OnlyAlpha P7.2 — Research Calculation Backend & Deterministic Execution

你正在维护仓库：

https://github.com/zongxin1993/OnlyAlpha

目标阶段：

> **P7.2 — Research Calculation Backend & Deterministic Execution**

本阶段不是简单增加几个 vectorized Indicator，也不是提前实现 Research Runtime。

P7.2 的核心目标是从第一性原理建立 OnlyAlpha Research Calculation 的正式执行基础：

> **给定一个经过完整验证的 immutable Dataset Snapshot，以及一个已经 resolved 的 canonical Calculation Graph，OnlyAlpha 必须能够在完全不依赖 Trading Runtime / Engine / Cluster / Strategy / Broker / Account 的情况下，通过 exact RESEARCH backend 确定性执行 Calculation DAG，并得到与 Calculation semantic contract 一致的 canonical Research Calculation output。**

最终建立：

```text
Verified Dataset Snapshot
        +
Canonical Calculation Graph
        +
Exact RESEARCH Backend
        ↓
Deterministic Research Calculation Execution
        ↓
Canonical Calculation Output
```
