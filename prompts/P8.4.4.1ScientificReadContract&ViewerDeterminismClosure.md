# 20. Stage 11 — Exact Graph External Source Projection

Core Graph binding 支持：

```text
reference.node_fingerprint
OR
reference.source
```

但 Web projection 当前只表达 node dependency。

修复层只能是：

```text
presentation model / graph projection
```

不要修改 Core Graph。

可以增加最小 presentation node 类型，例如：

```text
CALCULATION
EXTERNAL_SOURCE
```

或一个小 union。

External source stable presentation ID 示例：

```text
external-source:bar.close
```

必须明确：

```text
presentation ID
!= semantic fingerprint
```

它：

```text
不写回 backend
不参与 graph fingerprint
不参与 candidate identity
不参与 execution
```

对于：

```text
reference.source = "bar.close"
input_name = "close"
```

Exact Graph 应表达：

```text
external-source:bar.close
    → calculation-node

label:
bar.close → close
```

多个 node 使用同一个 source 时，只创建一个 deterministic presentation source node。
