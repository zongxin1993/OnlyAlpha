# 9. Workstream A — 完整 Canonical Import Capability Scanner

## 9.1 当前问题

当前某些 guard 只识别：

```python
from onlyalpha.foo import Bar
```

即：

```text
ast.ImportFrom
```

但普通：

```python
import onlyalpha.foo
import onlyalpha.foo as foo
```

可能没有进入 exact capability set。

这使 CLI / Route / Worker guard 可能被普通 Python import 写法绕过。

---

# 9.2 目标

建立一个最小、共享、确定性的 import scanner：

```text
ast.Import
+
ast.ImportFrom
```

统一 canonicalize 成稳定表示。

例如：

```python
import onlyalpha.application.strategy_authority
```

canonical:

```text
("module", "onlyalpha.application.strategy_authority")
```

```python
import onlyalpha.application.strategy_authority as authority
```

仍 canonical:

```text
("module", "onlyalpha.application.strategy_authority")
```

```python
from onlyalpha.application.strategy_authority import OnlyStrategyPromotionApplicationService
```

canonical:

```text
("symbol",
 "onlyalpha.application.strategy_authority",
 "OnlyStrategyPromotionApplicationService")
```

alias 不影响 authority identity。

---

# 9.3 不要过度抽象

可以放在：

```text
tests/architecture/_p9_k0_guard_helpers.py
```

如果多个 test 文件确实复用。

否则保持本地 helper。

不要新建通用 Architecture Framework。
