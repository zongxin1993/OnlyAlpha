15. API SERIALIZATION CONTRACT
============================================================

------------------------------------------------------------
15.1 Decimal
------------------------------------------------------------

Research statistic Decimal 必须无损。

禁止：

    Decimal
      ↓
    float
      ↓
    JSON number

正式 transport：

    Decimal
      ↓
    canonical decimal string

例如：

  "statistic_value": "0.071200000000"
}

NULL：

{
  "statistic_value": null
}

保持 Artifact 当前 Decimal(38,12) 语义。

不要通过 JavaScript-safe number 假设降低精度。

------------------------------------------------------------

正式保留：

    ts_event_ns: int64 semantic

API：

{
  "ts_event_ns": 1780000000000000000
}

不要只返回格式化 datetime 从而丢失 exact nanosecond value。

created_at 可作为 UTC ISO-8601 transport string：

    ...Z

但它是 audit value，不是 Statistic event-time authority。


------------------------------------------------------------
15.3 Identity
------------------------------------------------------------

所有 fingerprint：

- lower-case SHA256；
- exact string；
- 不截断；
- 不创建 human alias 替代正式 identity。
