# 27. Canonical Content Fingerprint

推荐使用 streaming SHA256，避免大型 Dataset 构造巨大 JSON。

伪代码：

```python
digest = sha256()

for bar in canonical_rows:
    payload = only_canonical_json(bar.to_dict()).encode("utf-8")

    digest.update(len(payload).to_bytes(8, "big"))
    digest.update(payload)

content_fingerprint = digest.hexdigest()
```

如果 current canonical API 能提供更加一致的 byte representation，可以使用。

必须测试：

```text
fresh process
same semantic data
→ same content fingerprint
```

不要用：

```text
RuntimeError("something went wrong")
```

处理正式合同错误。

---

# 79. 性能原则

P7.1 首要目标仍然是正确性。

但百万级 Bars 不能通过构造完整巨型 JSON 才计算 hash。

应使用：

```text
streaming hashing
Arrow columnar encoding
bounded intermediate representation
```

不要为了性能：

```text
skip validation
use float
skip fingerprints
hash only Parquet bytes
```

---

# 80. 内存原则

第一版如果 materializer 把完整 Dataset 放入内存，需要评估当前目标规模。

如果可以在保持代码清晰前提下实现：

```text
instrument-by-instrument validation
canonical partition generation
streaming fingerprint
```

应优先。

但不要在 P7.1 引入：

```text
distributed execution
complex external sort
multiprocessing scheduler
```

如果当前实现需要先有限内存 materialization才能保持正确性，也可以接受，但应明确边界并有合理 scale test。
