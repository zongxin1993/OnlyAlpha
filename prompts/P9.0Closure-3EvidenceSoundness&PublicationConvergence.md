```text

10. PostgreSQL Strategy catalog/Freeze records are projections,

12. No distributed transaction / 2PC.

13. Runtime remains read-only.

14. strategy_fingerprint remains the sole Strategy identity.
```

Do not introduce a second Strategy publication identity as execution identity.

# 37. PostgreSQL Projection

PostgreSQL should be recoverable from immutable semantic truth.

Create/extend a reconciliation operation conceptually:


```text

↓

↓
```

# 38. Projection Conflict

# 39. Freeze Operation Ordering

Design for crash recovery rather than pretending everything is one transaction.

One acceptable conceptual sequence:

```text
1. verify Research/Candidate/Evidence/Admission

2. construct Strategy Revision

3. construct immutable Freeze semantic relation

4. atomically/deterministically publish semantic frozen truth

5. project Strategy catalog + Freeze audit/provenance to PostgreSQL

6. return success
```

If step 5 fails:

```text
semantic truth remains durable
operation may report projection failure
restart/reconciler can converge
```

Runtime behavior must be determined by semantic publication completeness, not DB availability.
