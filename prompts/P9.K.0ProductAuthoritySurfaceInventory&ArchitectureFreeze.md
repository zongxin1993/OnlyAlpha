# 3. 第一性原理

OnlyAlpha 长期工程原则不是“功能越多越好”，而是：

```text
one fact
→ one authority

one semantic identity
→ one deterministic interpretation

one product transition
→ one legal path

unknown / ambiguous / partially verified
→ fail closed
```

P9.0 已经把 Strategy 语义链收敛为：

```text
Research
→ exact Candidate
→ unique Freeze
→ immutable Strategy Revision
→ strategy_fingerprint
→ exact Strategy Execution
→ StrategyDecision
```

其中：

```text
strategy_fingerprint
=
唯一 Strategy semantic / executable identity
```

不得在 P9.K.0 引入任何第二 Strategy identity。

Candidate 不能执行。

Candidate → Strategy 只能由正式 Freeze authority 完成。

Runtime 只能读取冻结后的 Strategy authority，不能获得 Strategy publication capability。

Promotion 必须继续保持 append-only。

Research Execution Evidence、Equivalence Evidence、Freeze relation、Strategy Revision 等 P9.0 已冻结语义，本任务必须保持零变化。
