27. Alignment Semantics
======================================================================

+

作为 pair identity。

对于每个 timestamp t：

    feature observation exists
    AND target observation exists

不要隐式 forward-fill。

28. IC 定义
======================================================================

IC：

对每个 observation timestamp t：

PearsonCorrelation(
    feature values across eligible instruments,
    target values across eligible instruments
)

输出至少包含：

ts_event_ns
value
sample_count
status

如果：

sample_count < minimum_observations

则：

value = NULL
status = INSUFFICIENT_OBSERVATIONS

======================================================================
29. Rank IC 定义
======================================================================

Rank IC：

对每个 observation timestamp t：

1. 对 feature values 使用 exact AVERAGE tie ranking。
2. 对 target values 使用 exact AVERAGE tie ranking。
3. 对 rank vectors 计算 Pearson correlation。

不得简单调用第三方：

corr(method="spearman")

然后依赖 undocumented/default semantics。

Tie / null / rank / numeric semantics 必须由 OnlyAlpha authority 明确。
