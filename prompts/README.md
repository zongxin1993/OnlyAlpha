# Historical Prompt Records

Files in this directory are historical implementation inputs. They are not authoritative descriptions of the current architecture, product scope, implementation state, or certification verdict.

Use current executable source and public interfaces first, then current tests and architecture gates, accepted ADRs, `AGENTS.md`, current architecture documentation and roadmap, and external certification evidence for an immutable subject SHA. A prompt may explain why work began; it cannot prove that the work was implemented, verified, or certified.
