# 7. Work Package A — Deployment Semantic-Store Coherence Closure

这是当前唯一真正的 architecture blocker。

## 7.1 当前问题

当前系统存在两个合法 authority plane：

```text
Operational Plane
→ PostgreSQL

Semantic Plane
→ immutable USER_DATA_ROOT/research/*
```

问题不是 dual-plane 本身，而是：

> 当前没有正式 durable fact 证明“这个 PostgreSQL Research deployment 与哪个 immutable semantic-store namespace 属于同一个 coherent deployment”。

当前代码可以出现：

```text
API:
DB1 + root A

Worker:
DB1 + root B
```

两者各自只验证本地 root 可读/可写，因此可能同时启动。

Worker 可以：

```text
claim Run
→ execute
→ Result R written under B
→ Artifact A written under B
→ fenced PostgreSQL finalization
→ Run COMPLETED
```

但 API 从 DB 读到 A 后去 root A 查询，得到：

```text
RESEARCH_ARTIFACT_NOT_FOUND
```

这个错误必须在新 semantic work 被 admit/claim 之前 fail closed。

## 40.5 Startup silent repair

## 40.8 Mock final browser proof

Mock Playwright 可保留，但不能替代 real product E2E。
