# 9. Missing DAG Input / Missing Upstream Output

构造 execution-level invalid dependency situation，例如：

```text

requires Node A.output
```

Executor 必须 fail closed。

不得允许：

```text

```

注意：

Calculation Graph validation 和 Execution validation 是不同层次。

即使合法 Graph 通常已经阻止这种状态，Executor 自身仍应保持 defensive invariant。

测试应尊重当前 public/private API。

不要为了造测试破坏模块封装。

---

# 10. Non-canonical Instrument Rows

检查当前 Executor 对 instrument rows 的 canonical ordering contract。

至少覆盖：

```text
timestamps out of order
```

以及：

```text

```

如果当前语义要求：

```text

```

则测试必须锁死。

原因：

rolling calculation 的结果依赖 series order。

不能允许：

```text

+
different physical order
→ different calculation output
```

进入 canonical Research Calculation。
