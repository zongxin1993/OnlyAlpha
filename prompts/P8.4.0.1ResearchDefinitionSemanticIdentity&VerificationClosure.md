
# 16. V1 采用 Three-Valued Boolean Semantics

除非重新阅读当前代码发现已有明确冲突，否则冻结：

```text
TRUE
FALSE
UNKNOWN(NULL)
```

Comparison：

```text
NULL < value
→ NULL

NULL > value
→ NULL

NULL == value
→ NULL

NULL != value
→ NULL
```

Boolean：

```text
TRUE  AND TRUE  = TRUE
TRUE  AND FALSE = FALSE
TRUE  AND NULL  = NULL

FALSE AND TRUE  = FALSE
FALSE AND FALSE = FALSE
FALSE AND NULL  = FALSE

NULL AND TRUE   = NULL
NULL AND FALSE  = FALSE
NULL AND NULL   = NULL
```

OR：

```text
TRUE  OR TRUE   = TRUE
TRUE  OR FALSE  = TRUE
TRUE  OR NULL   = TRUE

FALSE OR TRUE   = TRUE
FALSE OR FALSE  = FALSE
FALSE OR NULL   = NULL

NULL OR TRUE    = TRUE
NULL OR FALSE   = NULL
NULL OR NULL    = NULL
```

NOT：

```text
NOT TRUE  = FALSE
NOT FALSE = TRUE
NOT NULL  = NULL
```

---

# 17. Terminal NULL Semantic

明确冻结：

```text
ELIGIBILITY
ENTRY_SIGNAL
EXIT_SIGNAL
```

都是：

```text
nullable BOOLEAN semantic facts
```

即：

```text
NULL stays NULL
```

禁止偷偷：

```text

```

原因：

```text
FALSE
=
condition is known to be false

NULL
=
condition cannot currently be determined
```

这是不同的 Research evidence。
