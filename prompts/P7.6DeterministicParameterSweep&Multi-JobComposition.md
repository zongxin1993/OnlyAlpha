# 0. 任务定位

你正在修改 OnlyAlpha。

本任务是：

> **P7.6 — Deterministic Parameter Sweep & Multi-Job Composition**

这是 P7 Research Semantic Core 从“单个确定 Research Job”向“有限参数空间 → 确定性展开 → 多个 Research Job → 可复用 / 可重入的批量 Research Execution”演进的正式阶段。

P7.6 的目标不是实现高级优化算法，而是建立 **OnlyAlpha 的 Research Composition Layer**。

必须使一个有限、显式的参数空间能够被确定性地映射为一组有序、可验证、可重入、可复用的 Research Job，同时继续复用现有 Dataset / Calculation / Result / Job authority。

# 12. Template Reference 与 Calculation Reference 分离

materialization 前依赖应使用 template-local reference，例如：

```text

)
```



# 15. Topological Materialization

materialization 必须按 template DAG 的 deterministic topological order：

```text
1. validate template DAG
2. canonical topological order
3. for each template node:
     resolve this Cell parameters
     resolve actual upstream fingerprints
     call existing Calculation type/parameter semantics
     create CalculationDefinition
     obtain node fingerprint
4. build OnlyCalculationGraphDefinition
5. run existing Graph validation
```

禁止简单修改一个 node 的 parameters 而保留旧 upstream/downstream fingerprint binding。

# 19. Canonical Parameter Space

推荐语义：

> candidate collection 是 semantic set，不是 execution-order instruction。

因此：

```text
period=[20,5,10]
```

与：

```text
period=[5,10,20]
```

应生成相同 canonical expansion。

同理：

```text
dimension A,B
```

与：

```text
dimension B,A
```

应产生相同 ordered Cells。

Canonical order 必须基于稳定 target key + parameter name + normalized scalar ordering，不依赖：

```text
dict order
set order
filesystem order
hash seed
plugin incidental discovery order
```

---

# 58. 最终原则

P7.6 的目标不是：

> “写一个 for-loop 跑参数。”

而是：

> **正式定义 OnlyAlpha 如何把一个有限参数研究问题，无歧义地编译成现有 Calculation / Job / Result authority 可以执行和复用的确定性 workload。**

必须始终保持：

```text
Sweep = Composition
```

而不是：

```text
Sweep = Second Calculation Engine
```

必须保持：

```text
Template Locator != Calculation Identity
```

必须保持：

```text
One Cell
→ one existing calculation_fingerprint
```

必须保持：

```text
Recovery
=
deterministic re-entry
+
verified immutable Result reuse
```

必须保持：

```text
No Sweep DB
No Trial DB
No Scheduler
No hidden optimization state
```

质量边界必须明确：

```text
P7.x increment
→ VERIFIED
→ continue within P7
```

而不是：

```text
every P7.x
→ Final-SHA Certification
```

整个 P7 完成时：

```text

```

除非某个中间 increment 被显式定义为高风险 certification checkpoint。

```text
        ↓
```
