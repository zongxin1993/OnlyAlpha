# 8. P7.6 最关键的新发现：不能只替换 Definition.parameters

这是硬约束。

禁止实现：

```python
replace(existing_definition, parameters=new_parameters)
```

也禁止盲目：

```python
type_definition.resolve(
    new_parameters,
    old_input_bindings,
    old_warmup,
)
```

原因：

> **Calculation Definition 中存在 parameter-derived semantics。**

当前官方 Indicator 已经证明：

```text
period
→ warmup.minimum_observations
```

```text
price_field
→ bar.close / bar.volume source binding
```

MACD：

```text
fast_period
slow_period
signal_period
→ constraint validation
→ derived/default warmup_bars
→ warmup semantics
```

ATR v2：

```text
exact high / low / close source binding
```

因此 Sweep 不能产生：

```text
parameters = new
warmup = old
source binding = old
```

这种“部分新、部分旧”的非法 resolved Definition。
