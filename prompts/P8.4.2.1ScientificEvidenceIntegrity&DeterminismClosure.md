# 2. 第一性原理

## 2.1 一个事实只能有一个 authority

必须保持：

```text
Dataset Snapshot
→ exact Market truth

Calculation Result
→ exact Calculation output truth
→ exact Signal value truth

Statistics Result
→ exact Statistics truth

Specification V2
→ requested Scientific Evidence membership

Candidate fingerprint helper
→ Candidate identity construction

Result Plan V2
→ exact expected Research composition

Research Result V2
→ exact actual immutable upstream references

Scientific Artifact V2
→ derived portable immutable projection

Research Query
→ deterministic Artifact-only read projection

Web
→ presentation only
```

严格禁止新增：

```text
ScientificEvidenceStore
CandidateStore
SignalStore
GraphStore
PredicateResultStore
PredicateRegistry
PredicateRuntime
ScientificResultStore
ArtifactCatalogAuthority
```

## 2.2 下游只能引用、验证、投影上游 authority

如果上游已经确定某个事实，下游不得重新计算或推断。

正确：

```text
existing authority fact
→ exact reference
→ validation
→ projection
```

错误：

```text
existing authority fact
→ downstream recomputation / inference
```

## 2.3 同一个 semantic identity 只能有一个 semantic result

如果：

```text
research_result_fingerprint = R
```

Scientific Artifact logical identity 必须唯一。

并发发布相同内容：

```text
A → EXECUTED
B → REUSED
```

同一 Research Result identity 出现不同 Artifact semantic content：

```text
DETERMINISTIC_ARTIFACT_CONFLICT
```

绝不能：

```text
overwrite
last writer wins
silent replacement
race-only random commit failure
```

## 2.4 Portable self-contained 不是“文件能打开”

Scientific Artifact 必须在 Dataset / Calculation / Statistics / Research Result stores 都不可用时，仍能通过自身证明：

```text
exact file set
byte integrity
logical integrity
canonical ordering
unique logical keys
series axis completeness
membership consistency
Signal role uniqueness
Graph membership
Result linkage
```

## 2.5 依赖必须单向

不能为了 fresh-process Predicate composition 形成：

```text
Definition
→ Specification
→ Definition
```

如果 Predicate primitives 被 Definition Resolver、Specification Resolver、Runtime Factory 共同使用，它们的真实 owner 应为 Research Calculation。

# 6. Closure B — Scientific Artifact Deterministic Publication

Scientific V2 Store 必须达到 V1 immutable store 已经具备的 deterministic publication 语义。

正确流程：

```text
candidate
↓
validate
↓
stage
↓
write
↓
verify staged Artifact
↓
atomic rename
```

如果 target 在开始时已存在：

```text
load_verified(existing)

same artifact_content_fingerprint
→ REUSED

different artifact_content_fingerprint
→ DETERMINISTIC_ARTIFACT_CONFLICT
```

必须处理 race：

```text
A check absent
B check absent
A rename success
B rename raises OSError
```

B 应：

```text
if target exists:
    load_verified(winner)

    same semantic content
    → REUSED

    different semantic content
    → DETERMINISTIC_ARTIFACT_CONFLICT
```

rename 失败且 target 不存在才是真正 commit failure。

严禁：

```text
os.replace
删除 winner
覆盖 existing Artifact
last-writer-wins
```

# 16. Closure L — Variable Typed Scalar Canonicalization

保持：

```text
DECIMAL → string
INTEGER → string
BOOLEAN → bool
STRING → string
NULL → typed value columns all null
```

不要转 float。

## INTEGER canonical form

接受：

```text
0
1
-1
123
-999
```

拒绝：

```text
+1
01
-0
1.0
1e3
```

推荐：

```regex
^(?:0|-?[1-9][0-9]*)$
```

## DECIMAL

必须：

```text
parseable Decimal
finite
canonical according to current materializer serialization
```

优先保持当前：

```python
format(value, "f")
```

可验证：

```python
parsed = Decimal(raw)
parsed.is_finite()
format(parsed, "f") == raw
```

先确认 trailing-zero semantics 与当前 materializer 一致。

不要主动 normalize scale。

Signal `None` 必须继续保留，严禁 `None → False`。

# 43. 最终工程原则

每个改动都必须回答：

```text
它关闭了哪个真实歧义？

它修复了哪个真实 determinism hole？

它保证哪个 fact 只存在一个 authority？

它让哪个 immutable object 更能自证完整性？

它是否减少而不是增加架构复杂度？
```

回答不了，就不要做。

最终目标不是更多模型、更多类、更多 Store。

最终目标是：

```text
Definition scientific intent
        ↓
Specification V2
        ↓
Fresh Worker reconstruction
        ↓
same Candidate identity
        ↓
same exact Result Plan
        ↓
same immutable upstream Results
        ↓
same Research Result
        ↓
same Scientific Artifact semantic identity
        ↓
same Artifact-only Query projection
```

即使发生：

```text
process restart
worker retry
duplicate execution
concurrent Artifact publication
upstream authority removal after Artifact commit
portable Artifact reload
```

系统仍然只能收敛到：

```text
one semantic fact
one canonical identity
one deterministic result
```

任何不一致：

```text
fail closed
```

这才是 P8.4.2.1 完成标准。
