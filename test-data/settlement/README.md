`common-v1.json` is a controlled language-neutral cash-security fixture with a full explicit Domain Calendar, October 26 holiday, compiled six-axis policy, immutable owner/Position/Allocation/economic inputs and non-secret technical provenance. It is not live-market or production deployment evidence. The Python/native checker validates the Calendar roundtrip and actual Python Market schedule/Settlement Authority common behavior against independent T0/T1/T2/T3 expected dates, then native economic maturity and real fresh-process checkpoint continuation. IDs/codecs are intentionally not equated. Future booking completeness, whitespace/venue rejection, safe pre-reserved slots and strict restore are independently proved Rust corrections/extensions; no whole Python parity is claimed.
