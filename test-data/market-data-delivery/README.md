# Delivery independent routing vectors

`routing-v1.jsonl` is hand-specified from PRIMARY_ONLY semantics: explicit subscription IDs/periods/primary, provider Bar
operations, and literal expected Cluster IDs. The separate same-time events ensure no global cursor incorrectly suppresses a
different Cluster. Expected values are not generated by either implementation. Rust uses real State/Delivery plus fresh-owner
checkpoint replay; Python uses the real Pipeline/Dispatcher and deterministic component fixtures. Only common valid routing is
compared, not component wire schemas, readiness, callback ownership or whole-module parity. Coercive Python reader examples
remain ignored audit observations, not committed tests that require preserving a Python bug.
