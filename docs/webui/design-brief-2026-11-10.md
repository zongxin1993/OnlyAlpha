## 设计语言

- shadcn 现代极简 + 量化高密度；桌面优先且响应式；专业低装饰；细边界、克制状态色。
- 暗色为默认主题，浅色可选；选择持久化（键 `oa-theme`，语义 `dark|light`），

## 布局契约

```text
#rail(200px 侧栏) │ #stage：ctxbar(仅工作台) + main + footer
```

- 侧栏：品牌行 → 导航两组（投研：总览/工作台/研究/策略/回测；基础设施：数据/系统），
  每项**图标 + 中文文字并列**（任何宽度下文字不得隐藏）→  rail-foot（主题、密度、设置）。
- 上下文条（ctxbar）**只属于工作台**：行情状态 chip、标的、时间范围 + 现有工具栏 portal。
  其余画面一律不用 ctxbar，标题以页内 `view-head`（h1 18px/650 + 副标题 faint）呈现。
- footer.status：仅承载真实可得信息（版本、系统健康入口）；无 API 支撑的内容宁缺毋假。

## 响应式契约（验收门槛）

| 断点 | 行为 |
|---|---|
| ≥1240px | 工作台二分：自选竖列(210px) + 图表；指标/因子在图表下方双卡并列 |
| 900–1239px | 工作台保持二分；研究/策略/回测 detail 降为单列 |
| ≤900px | 侧栏转 overlay 抽屉（☰ + 遮罩 + Esc + 选择后自动关）；☰ 同时出现在 ctxbar 与页内标题行 |
| ≤880px | 工作台单列，顺序：图表 → 指标行 → 自选 |
| ≤768px | KPI 带 4→2 列；≤640 转 1 列且分隔线转向 |
| 任意 | 表格进 `.tw{overflow-x:auto}` + 内部 min-width，页面级零横向溢出 |

视口验收矩阵：390 / 640 / 768 / 880 / 1024 / 1152 / 1440。

## 文案与状态纪律（迁移时必须保持）

- 徽章只放短状态词；限定与后果进正文字段（例：徽章「取消」+ 结果「证据保留可查」）。
- 错误提示说明发生了什么、操作是否生效、如何继续；UNKNOWN 保持可见未确认。
- 演示/占位数据在开发期必须页面内诚实标注；正式版一律真实数据 + 来源与样本范围。
- LIVE 相关操作一律本人授权路径，界面不代办、不暗示可代办。
