# Rust Backtest Replay Driver / Run Loop

`crates/onlyalpha-backtest/` composes finite market replay outside the Trading Kernel. `Inputs` pins immutable closed RAW revision0 Bars, exact Source/Snapshot/Dataset binding/DataVersion, declared priority and row count. `RunSpec` binds work identity, complete Execution configuration, separate Kernel and driver artifacts, initial virtual time, and the participant's exact Generation/Strategy revisions/Source set. A fingerprint binds bytes; it does not authenticate a producer or grant Product Runtime authority.

The current trusted Application adapter `onlyalpha_calculation_worker.backtest_dataset.load_dataset_inputs` loads an exact economic binding and a bounded verified Dataset table through the existing owning readers. It decodes that same table, preserves opaque DataVersion, and rejects unsupported economic facts or a different Market Product composition. It never substitutes a current database query. Runtime input admission, authorization, artifact availability and formal Generation activation remain the responsibility of the admitted R5 composition.

## Ordering and actual participants

The merge key is event nanoseconds, instrument identity, canonical BarType record, declared Source priority, Source identity, sequence and full occurrence digest. Actual Order owner previews allocate the prospective identity without changing official state; canonical ADMIT produces the real identity. Actual market/fee admission precedes Rust Risk admission. Normalized Execution inputs retain causal market occurrence, Strategy decision, policy and raw Broker/fee outputs in the durable replay step.

The selected plugin composition admits one Strategy/Source/instrument, Generic T0 cash with multiplier1 and configured LIMIT long-open/long-close requests, at most16 requests and64 declared fill slots. Python plugin time must be microsecond-aligned and fit the current u64 transport; unsupported precision fails explicitly. Native input ordering and Clock retain arbitrary-precision nanoseconds. These are current implementation boundaries, not changes to the Constitution's market/runtime scope. SIM/LIVE are rejected by this driver. No real venue gateway is reachable through its closed Replay worker operation.

Raw Broker source sequence remains in the retained plugin DTO; canonical Execution uses its existing normalized Runtime ingress ordinal.
