# Rust Fee authority

Fee is an isolated market-neutral semantic library under ADR 0139 and Fee Contract / ADR 0059–0061. It owns explicit immutable authority selection, exact rule assessment/estimation, per-component accrual/application, typed local queries, external evidence lineage, adjustment planning and active risk blockers. Market rates/basis translation, SDKs, storage drivers and Runtime activation remain outside. No Web business acceptance or Python retirement follows.

Catalog holds explicit MARKET/BROKER sources, scoped versioned schedules and typed rule IR. Bindings freeze exact ORDER_FIXED rules and FILL_EFFECTIVE family/scope. Resolution must be unique; no missing-as-zero, latest selection, inferred fee scope or FX. Formula uses exact bounded Decimal, explicit rounding quantum/mode and bounds order. Estimates require a maximum split count for split-sensitive FILL rules, reserve gross charges and never net rebates against funding.

Manager owns applications and component accrual; committed command history, exact config and replay validate checkpoints. Exact duplicate input returns its immutable result; changed identity conflicts. Corrections append evidence revisions and adjustment deltas, never edit applications. Scope is tagged TRADE/ORDER/STATEMENT (UTC integer interval, account/broker/currency); missing components differ from zero. Reconciliation compares the union of local/external/prior-adjustment components. Only a valid revision in a blocker's lineage can resolve it; Risk supplies risk-change classification.

Execution consumes the Fee manager's opaque application and retains no second cumulative target authority. Its existing explicit admitted fee-target input remains a trusted owning Runtime port, not authenticated merely by its transport hash. The adapter's authentication remains outside this non-activated library, as for existing market/settlement inputs. Native assessment and normalized admitted targets are distinct explicit producer paths; neither is a fallback. The fee checkpoint belongs to the exact committed Execution projection so recovery never reruns current schedules. Existing component schema evolves explicitly; no old-format fallback is added.

Python reference is audited by responsibility: pure formula/rounding/resolution/accrual/reconciliation correspond to the library; Runtime transaction building stays Execution, basis/rates stay plugins. Shared independent vectors plus actual Python engine/accrual and real Rust Execution consumers prove common values. Identity/format differences retain distinct provenance. Missing-proof, wrong-owner, revision, boundary and persistence faults are mandatory negative tests.
