# backtest 性能基准

## 职责与范围

直接测本模块的正式公开入口；具体操作见共享 [inventory.json](../../test-data/backtest-benchmarks/inventory.json)。不产生 Product 准入或完成事实，不以组件计时替代 Web 验收。

## 输入与口径

使用受控私有滚动因子程序、原 Strategy Executor、市场／费用端口和实际交易组件，测有限内存执行（`memory.execute`）与结果读取验证（`result.read`）。不再依赖旧 SQLite 保留目录或 `OA_BENCH_RUNTIME`。

## 执行

- 统一运行器（默认 `retained` 模式，3 轮固定样本，`memory.execute` 与 `result.read`）：`cargo bench --frozen --offline -p onlyalpha-backtest --bench retained` 或 `python -m scripts.run_rust_benchmarks reference --crate backtest --target retained --output <新结果目录>`。
- 多档规模对比：`cargo bench --frozen --offline -p onlyalpha-backtest --bench retained -- --memory` 或 `-- --signal`。

输入/元数据准备在计时外；各阶段含其内部复核。旧 SQLite `terminal.read` / `terminal.verify_cut` 入口已随 ADR 0151 退役，不再作为新基准的隐含输入，也不与旧 SQLite 样本直接比较声称优化。

## 限制

原始样本与环境/构建身份外存；输入/结果不匹配或样本不完整禁止比较。历史工件值仅用于技术输入绑定，不赋予当前可执行文件历史读取 Authority。原 300/120 秒门槛不变，无新 CI 性能阈值。

## 有限内存执行基准

`cargo bench -p onlyalpha-backtest --bench retained -- --memory` 使用同一受控私有滚动因子程序、原 Strategy Executor、市场／费用端口和实际交易组件。分别测准备、逐 Bar 交易执行和最终结果整理。场景为平坦无成交、循环信号交易、模型拒绝和资金拒绝；64／128／256／1024 根各三轮，所有轮次核对完整经济结果、曲线、事件、原始信号和买入持有报价的摘要相等。吞吐分母是 K 线根数，包含 warmup，不将 OPEN／BAR 两步算作两根。

保留计数依次为输入、原始信号、驱动事件、sample 收盘记录、经济输入；保留编码字节只计逻辑载荷，不含类型 owner、幂等索引和分配器开销，不能当作 RSS。基准没有恢复整套组件或逐 Bar 全组件 checkpoint 的步骤。当前 typed 经济 owner 内部仍有历史检查及复制，基准不承诺其 CPU 工作量为线性。

2026-11-15 固定 onlyalpha-dev，Linux aarch64，Rust 1.99.1，release；依赖编译缓存已热，每轮重新创建 owner，未清 OS 页缓存。工件 SHA256 `2b6f53f974bb7e665ce537bc3f98f763f8e1fa49606c993a73cae0a6e0c150bc`；冻结源码 `ffbaa78652e556ded2dfa62e1bad6cb1722af6c294bd49d0d73573a6359e6508` 是固定投影身份，不能替代 Git 提交。48 个交易样本及 12 个信号样本均成功。原样本、工件和机器身份外存于主工作区 `test-results/strategy-research-framework-stage5-performance-final/`。

`--signal` 单独执行共用的七节点私有程序／算子／谓词信号图，64／128／256／1024 根三轮中位吞吐分别为 1583.08／1521.29／1453.69／1331.28 根／秒，收尾分别为 2.175／3.058／5.195／14.740 ms；各轮完整计算与信号摘要一致。它用于区分信号计算和完整交易，不包含 Target、准备或发布。

独立监控进程只启动基准可执行文件，排除了编译子进程；信号样本最大 RSS 为 72348 KiB，交易样本为 291280 KiB。这是整个基准进程的高水位，含样本准备及结果保留，不是某个 owner 的独占内存或单阶段峰值。历史 `strategy-research-framework-stage5-performance/` 结果保留，不能与本轮绕过工件身份检查直接比较。

该技术场景不证明 ClickHouse 准备、PostgreSQL 发布、正式作业或 Web 端到端验收。未增加性能硬门槛。
